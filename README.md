# Full Page Screenshot

Capture full-page screenshots directly in Chrome. Annotate, download, or copy to clipboard. No login, no signup, no tracking.

## Features

- Full-page capture with automatic scrolling and stitching
- Annotation tools: pen, rectangle, arrow, blur
- Export as PNG, JPEG, or WebP
- Copy to clipboard
- Context menu and keyboard shortcut (`Ctrl+Shift+S` / `Cmd+Shift+S`)
- Light/dark popup theme
- All settings stored locally

## Install

1. Open `chrome://extensions/`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the `dist` folder after building

## Build

```bash
npm install
npm run build
```

## Usage

1. Click the extension icon or right-click anywhere and select **Capture Full Page Screenshot**
2. Wait for the capture to complete
3. Use the annotation toolbar in the popup to mark up the screenshot
4. Click **Download** or **Copy** to export
