Capture the entire web page

A Chrome extension for capturing full-page screenshots with annotation tools, multiple export formats, and zero friction. No login, no signup, no tracking — just open and capture.

Manifest V3 TypeScript Privacy First Offline
01 — Features

Built for speed, designed for clarity.

Everything you need to capture, edit, and share full-page screenshots — without leaving your browser.

📸

Full Page Capture

Automatically scrolls and stitches the entire page into one seamless image. Works on SPAs, long articles, and lazy-loaded content.

✏️

Annotation Tools

Draw with a pen, add rectangles, highlight areas, or blur sensitive information directly on the screenshot.

💾

Multiple Export Options

Download as PNG, JPEG, or WebP. Copy to clipboard with one click. Custom filename templates supported.

⚡

Multiple Triggers

Capture via toolbar icon, right-click context menu, or keyboard shortcut. Ctrl+Shift+S / Cmd+Shift+S.

🔒

Privacy First

Zero network requests. No accounts, no telemetry, no analytics. All data stays on your device.

🎨

Light & Dark Theme

Popup adapts to your system theme preference. Clean, responsive UI from 250px to 600px wide.

02 — Install

Load it in under a minute.

Build the extension and load it as unpacked in Chrome or any Chromium-based browser.

01

Clone the repository

Grab the source code and navigate into the project directory.

02

Install dependencies

Run npm install to set up the build toolchain.

03

Build the extension

Generate the distributable bundle into the dist/ folder.

04

Load in Chrome

Open chrome://extensions, enable Developer mode, and click Load unpacked → select dist/.

$ git clone <repo-url>
$ cd fullpagescreenshot
$ npm install
$ npm run build
03 — Architecture

Clean separation of concerns.

The extension follows Manifest V3 best practices with a modular, testable architecture.

src/
├── manifest.json — MV3 config, permissions, commands
├── background/
│ └── service-worker.ts — Context menus, action, commands
├── popup/
│ ├── popup.html — UI structure
│ ├── popup.ts — Capture logic, annotations, export
│ └── popup.css — Material Design styling
├── content/
│ └── capture.ts — Scroll capture + stitching
├── shared/
│ ├── types.ts — TypeScript interfaces
│ ├── messaging.ts — Tab messaging helpers
│ └── storage.ts — Local settings CRUD
├── utils/
│ ├── scroll-capture.ts — Async generator for viewport captures
│ ├── stitch.ts — Canvas compositing
│ ├── annotate.ts — Annotation canvas + history
│ └── export.ts — Download, clipboard, filename generation
└── icons/ — Toolbar and store icons

Data Flow

// Popup triggers capture
Popup → chrome.tabs.sendMessage → Content Script

// Progress updates broadcast to popup
Content Script → chrome.runtime.sendMessage → Service Worker → Popup
04 — Tech Stack

Modern tooling, zero bloat.

Built with performance, security, and maintainability in mind.

Manifest V3

Latest Chrome extension standard with service worker background, minimal permissions, and strict CSP.

TypeScript

Fully typed codebase with strict mode enabled. Functional patterns, JSDoc comments, and modular architecture.

ESBuild

Lightning-fast bundling with tree-shaking. Outputs clean ESM bundles targeting Chrome 120+.

Canvas API

Native browser canvas for stitching and annotation. No external image libraries or dependencies.

Chrome APIs

tabs, scripting, storage, downloads, runtime, contextMenus, commands — all used with least-privilege principle.

No Dependencies

Zero CDN links, zero analytics, zero telemetry. Works completely offline after installation.

Permissions

activeTab scripting contextMenus downloads storage commands
05 — Browser Support
